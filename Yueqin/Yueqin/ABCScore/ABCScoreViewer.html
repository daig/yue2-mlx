    Keyboard reference

    Click selects; Shift-click extends in one voice. Drag changes staff pitch. Left/Right moves selection; Shift extends. Up/Down changes staff pitch; +/− changes semitone. 3–8: thirty-second through whole. Period: dot. A–G: pitch. Enter / Shift-N: note entry (overwrites time and advances); Escape: close a panel or select. R: rest entry. T: tie. Command-Z / Shift-Command-Z: undo / redo. Command-C / X / V: copy / cut / paste. Space: preview both parts from selection. Key changes keep sounding pitches.
